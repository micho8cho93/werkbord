# Archive

sequence. They describe how the product *was* at the time, not how it is now, and nothing in the build or the tests reads
them. For the current design start at [ARCHITECTURE.md](../ARCHITECTURE.md), [STRUCTURE.md](../STRUCTURE.md) and
[PLANS.md](../PLANS.md).
