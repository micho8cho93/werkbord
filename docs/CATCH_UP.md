# Project Catch-Up

Home's **Since you were last here** section is assembled from recorded work. Opening Werkbord makes no model calls.

Personal counts tasks entering Done, excluding subsequent edits to Done tasks, and authenticated PR observations with an explicit merge timestamp. A finished agent run or direct Git merge is not counted as a completed task or merged PR. Team projects supply their permission-filtered completion and PR-merge activity. Duplicate PR identities and linked Personal handoffs/Team tickets count once within the recap interval. Counts open their supporting records; current attention opens Home's Needs attention section.

The shell keeps one interval per app session, independent of Home navigation. Launching the app or returning after thirty minutes hidden starts a new interval. Current attention stays live. A first visit establishes a baseline. Device-local storage contains timestamps and per-workspace cursors, never Team content. A disconnected workspace retains its last successful coverage checkpoint.

History is bounded to thirty days and a maximum of 200 projected changes per workspace. Team reads at most 200 recent activity entries per project. The UI identifies missing workspaces and incomplete coverage; zero is never used to stand for an unavailable source. Older workspace services without the projection appear unavailable for catch-up while their other summaries remain usable.

**Catch me up with Salie** refreshes authorised summaries, then opens a bounded explanation draft with measured events, workspace links, coverage and truncation information. The user submits the draft through their existing Salie conversation. A failed refresh does not send cached Team evidence. The recap itself is never generated by a model.

The neutral workspace summary contract adds optional `changes` containing coverage timestamps, cursor, incompleteness and plain, workspace-local event references. Each product owns its projection. The desktop shell combines projections without importing either product's execution code. Team's `/api/team/v1/catch-up` endpoint only reads authorised coordination history.
